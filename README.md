This is a clone of the popular website "Netflix". A one to one clone. 

**Step 1** 
Install docker

**Step 2**
Run docker composer up 

**Step 3**
Open localhost:5000

**Step 4**
Due to copyright restrictions, users should upload their own videos following the step-by-step process

**Step 5**
Enjoy the movie

**Bonus step**
Due to limitations, only movies below 500mb are allowed
